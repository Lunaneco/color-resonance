## 遊び方

画面に触れて音を有効にし、「はじめから」を選んでください。

- 物語: クリックまたは Enter で読み進めます。Ctrl 長押しでスキップできます。
- 戦闘: 味方と移動先の床を選び、表示されるメニューで行動します。E でターン終了、Esc で選び直します。
- 待機: 「待機」のあとで右上・右下・左下・左上を選びます。向きを確定して初めて行動を消費し、戻る・Escでは消費しません。味方のHP横にも現在の向きを表示します。
- マップの回転: ↶／↷ボタン、またはQ／Rキーで左右に90度ずつ回転します。0キーで初期の視点に戻ります。移動や攻撃の演出中は回転できません。回転しても位置・射程・背後判定は変わらず、移動の取り消しも使えます。
- 敵の向き: 足元の橙の矢印が正面、青の二本線が背後です。HPの横の矢印と敵の情報欄でも4方向を確認できます。選んだ味方の現在位置からの攻撃は、正面・側面（+10%）・背後（+25%）として情報欄に表示されます。
- 進行状況はブラウザのローカルストレージへ自動保存します。「設定」のファイル保存・読み込みで別のブラウザや端末へ引き継げます。物語の位置、育成、装備、難易度別の戦績、遊びの途中記録を含みます。戦闘そのものの途中状態は保存しません。
- BGM、効果音、文字の速さ・大きさ、演出の軽減、難易度は「設定」で調整できます。音なしでも開始できます。
- 新しい旅や記録の削除、ファイル読み込みは確認してから実行します。切り替え前の記録は1つ退避され、「設定」から戻せます。大切な記録はファイルにも保存してください。

マップの戦場には適正LVと選択中の難易度が表示されます。戦場や依頼を選ぶと「やさしい・ふつう・ハード」を切り替えられ、敵のLV・HP・攻撃力と、しずくの報酬が変わります。クリア回数・最高ランク・ミッション達成は難易度別に保存されます。以前のクリア記録は「ふつう」へ、旧「達人」の戦績と選択は「ハード」へ引き継ぎます。既存のハード記録があればクリア数・最高評価・ミッションを統合します。難易度は出撃時に固定され、再挑戦でも同じです。

町の「依頼」には物語の進行に応じて12件のサブクエストが追加されます。初級から最上級まで、それぞれの適正LVと選択した難易度を確認できます。初回の道具報酬は各難易度で1回ずつ受け取れます（道具の所持上限は各9個）。スマートフォンでは地図をスクロールして移動できます。

召喚は共鳴6を使い、登場時の大技のあと精霊が別ユニットとして3ターン戦います。宿しと召喚は重ねて使えます（同じ精霊は同時に1つまで）。心剣に宿す（エンチャント）は共鳴3・行動消費なしで、3ターンのあいだアリアの通常攻撃を毎ターン2回にします。1撃目のあと、同じ敵か別の敵に追撃できます。各攻撃に精霊の効果が付き、空振りも1回に数えます。移動は1回だけで、1撃目から移動を戻したり、技・魔法・道具に切り替えることはできません。追撃をやめるときは「待機」で向きを選びます。召喚は、別の精霊であれば重ねて呼べます（共鳴6ずつ。同じ精霊は同時に1体まで）。召喚と宿しは同時には使えません（召喚中は宿せず、宿している間は召喚できません）。召喚した精霊が倒された場合は、その戦闘中の再召喚と宿しが両方とも使えなくなり、精霊一覧とメニューに戦闘不能を表示します。他の精霊や習得済みの技は引き続き使えます。期限切れの帰還は戦闘不能に含めず、再挑戦・次の戦闘で制限を解除します。

精霊の召喚で絆+3、心剣に宿すと+2、精霊または宿した心剣の命中で+1、習得した技の使用で+2。精霊との絆は共通の強さを育てます。技の習得はエンチャント熟練と召喚熟練を別々に判定し、それぞれ8・20・40で3種類ずつ（4精霊×2系統×3種類、全24種）。宿すとエンチャント熟練+2、宿した通常攻撃の命中で+1。召喚すると召喚熟練+3、召喚した精霊の命中で+1。覚えた技の使用では系統の熟練は増えません。以前のセーブで習得済みだった技はそのまま使えます。新しい経路の熟練は0から育て、以前の絆を両方へ複製しません。「仲間・絆」で効果と習得条件を確認し、戦闘の「覚えた技」で使います。習得後は召喚や宿しなしでも使えます。絆のランクが上がると精霊や技の効果も上がり、敗北や中断でも絆・習得内容を引き継ぎます。

S評価の装備報酬はハードのみ。ボスがいる戦闘では土地固有のユニーク、通常戦ではステージ別の通常装備を獲得します。ふつうの初Sは虹のかけら×2・プリズムの粉×1、やさしいの初Sはそれぞれ×1です。強化素材は従来どおりクリア・ミッション初達成・初Sで獲得します。各難易度・各ステージで1回ずつ。所持済みの通常装備は価格の半分をしずくで受け取ります。伝説5戦もボス戦ハードSの対象です。過去の通常戦ハードS由来のユニークは通常装備に置き換え、同じ装備をボス戦ハードSでも獲得していれば保持します。装備中なら新しい装備のスロットへ移し、そのスロットが埋まっていれば所持品へ入れます。受取済み・最高評価・クリア回数は引き継ぎます。

アリア・クロム・精霊の成長上限はLV99です。上限でも戦闘・報酬・セーブを続けられます。

## 素材でスキルを強化

地図、町、「仲間・絆」の「スキル強化」から、精霊と習得系統を選んで全36種類の技を+3まで育てられます。素材袋には6種類を各999個まで保存します。強化前に所持数・必要数・次の効果を確認でき、素材不足や未習得の技は強化できません。

| 段階 | 共鳴の砂 | 精霊の素材 | 澄明の核 |
| --- | ---: | ---: | ---: |
| +1 | 3 | 2 | 0 |
| +2 | 6 | 4 | 0 |
| +3 | 10 | 6 | 1 |

精霊の素材は、グランが潮の雫晶、アイビーが若葉の結晶、スピネルが金継ぎの欠片、パレット王が虹彩の結晶です。攻撃は1段階あたり基礎威力+12%、回復と吸収は+5ポイント。守りは+2で1ターン、束縛は+3で1ターン延長（最大3ターン）。消費共鳴・射程・範囲はそのままで、絆の補正と重なります。

- **戦闘:** 毎回のクリアで砂と戦場に対応する精霊素材。やさしいは2/1個、ふつうは3/2個、ハードは4/3個。
- **ミッション:** 各ステージ・各難易度・各目標の初達成で砂1個と精霊素材1個。初S評価で核1個。装備報酬とは別に記録します。
- **遊び:** 評価C・B・A・Sを初めて達成するごとに砂と2種類の精霊素材。上位評価へ飛び級した分も受け取れます。難易度ごとに記録し、初Sで核1個。各遊びのハード初回クリアで、評価に関係なく核2個を追加で受け取れます。練習や失敗では獲得しません。
- **一部の店:** 灰色の街で砂・潮・若葉、石の村で砂・金継ぎ、虹の城下町で全6種を買えます。

強化と素材、報酬の受取状況は自動保存・ファイル引き継ぎに対応します。以前の装備・技・記録を保持し、新しい素材の報酬はアップデート後のプレイで獲得できます。

## 町の遊びと旅の手帳

地図の「遊び」と町の「色と音の休憩所」から、4種類のミニゲームを選べます。

- **星潮の航路:** 3列の海を先読みして星の宝を運ぶ、3海域の航海です。宝の連続取得で得点が増え、風を2使う疾走は宝と岩礁の傷が2倍。風1の護りで傷を防げます。2つの寄港地では船体回復・風力補充・秘蔵の宝を選びます。船体が残ったまま港へ到着すればクリア。第一幕の解放で遊べます。
- **灯台の色つなぎ:** 自分と上下左右の灯りが変わるパズルです。6・9・16個の盤面から選び、すべて点灯させます。必ず解ける盤面を生成し、ヒントと戻す操作を用意しました。第二幕の解放で遊べます。
- **精霊のこだま:** 色・記号・名前・音で示す順番を覚えて返します。3節を完成させます。自動再生と一音ずつ見る方法があり、音を消しても遊べます。第三幕の解放で遊べます。
- **結晶の連鎖:** 5×5の結晶を交換して、3つ以上そろえます。4つ以上で爆発する星結晶が生まれ、近くの星結晶も巻き込みます。消した個数×連鎖数が庭園の彩りになり、12個消すと次の一手が2倍。横一列を消す「虹の一閃」は1回だけ、手数消費なし。3つそろわない交換とヒントは無料。目標55/110/210、手数18/16/14。第四幕の解放で遊べます。

すべて時間制限なし、3難易度、練習、途中保存、再挑戦、最高成績に対応します。報酬は成績が上がった分だけ受け取れ、各遊びの難易度ごとに70・100・140しずくまで。練習では報酬や記録を変更しません。ハード初回の澄明の核2個は各遊びで1回（計8個）。初Sの核1個とは別の報酬です。アップデート前にハードをクリアしていた場合も、次の実際のクリアで新しいボーナスを受け取れます。素材袋が満杯なら入らなかった分を保存します。海・盤面・補充用の乱数・使用済みの切り札も途中記録に含め、再開やファイル引き継ぎで再抽選しません。失敗では所持品や最高成績を失いません。

タイトル、物語メニュー、地図の「手帳」から、読了章の振り返り、4精霊から届く12通の便り、思い出の画像、9種類の達成記録を確認できます。便りは精霊との出会いと絆8・20・40で開き、未読の章やまだ出会っていない精霊の内容は伏せます。手帳を開いても物語の再開位置は変わりません。

序章でリラが波に飲まれる場面には、新しいイベント画像を表示します。読み終えた後は手帳の「思い出」でも見られます。既存セーブの読み進めた位置は引き継ぎ、以後は行の識別子で再開位置を記録します。

## 生成素材のゲーム表示

戦闘のアリア・4精霊・6種類の敵、ルノワールと6種類の会話キャラクターに、[生成素材](assets/generated/)を使用しています。移動・攻撃・被ダメージ・技発動をコマで再生し、各精霊の召喚・心剣への宿しをアニメーション付きのカットインで表示します。透明の一閃・回復・4属性の力・小さな夜空・漆黒の波は、戦場上に対応したエフェクトを重ねます。人物情報や仲間画面にも素材を表示します。

`js/art.js` が必要なPNGシートだけを読み込み、動作と技の一度だけの再生・終了を管理します。読み込みに失敗した戦闘キャラクターは従来の描画に戻ります。プレイヤーの操作範囲や戦闘処理は同じです。

## ローカルで起動

リポジトリのディレクトリで次を実行し、http://localhost:8791/ を開いてください。

```sh
python3 -m http.server 8791
```

戦闘用のデータを `fetch` で読み込むため、`index.html` を直接開くのではなく、HTTPサーバーを使います。

## 公開と更新

GitHub Pages の公開元は GitHub Actions です。`main` ブランチへ変更を push すると、`.github/workflows/deploy.yml` がJavaScriptの構文とゲーム全体の回帰テストを確認し、成功した場合にゲーム本体と素材を自動で公開します。Actions 画面の「Deploy game to GitHub Pages」から手動実行もできます。

JavaScript・CSSを更新するときは、`index.html` の読み込みURLに付けた `v` の値も更新します。前のプログラムがブラウザに残っていても、同じ版の画面とゲーム処理を読み込めます。

## ゲームのテスト

Node.js 24 で次を実行してください。テスト用のHTTPサーバーは自動で起動・終了します。

```sh
npm ci
npx playwright install chromium
npm test
```

移動と取り消し、攻撃とターン進行、回復、精霊、勝敗と再挑戦、戦闘中断、終章の切り替え、難易度別の報酬・実績、サブクエストの条件、絆と36種類の習得技、独立した習得経路、素材獲得と重複防止、36技の強化と消費・実戦効果・保存、ハードS専用のユニーク装備、およびPC・スマートフォンの画面配置を確認します。敵の4方向の目印と攻撃位置の一致、敵ターン後の方向更新、タッチでの向き確認も対象です。生成素材の実描画・行動コマ・4精霊のカットイン・演出終了・会話キャラクター・素材読み込み失敗時の戦闘も確認します。テストでは独立したブラウザを使うので、プレイヤーのセーブデータは変更しません。

エンチャントの2回攻撃・追撃の対象切替・空振り・待機・ターン更新と期限・中断、待機の確定・取消、道具の二重消費、守りと召喚の期限、LV99の保存、ショップ購入、ミニゲームの解法・報酬・保存、ファイル読み込みの検証・復元、ログ中のオート停止、物語中断時の演出取消、手帳の公開条件とキーボード操作も対象です。物語の接続テストでは戦闘完了を代替し、全8章の命令と保存形式を確認します。戦闘自体は別のブラウザテストで確認します。

精霊4種の戦闘不能・後続ターンの再使用禁止・共鳴や熟練を消費しないこと・期限帰還と再挑戦、4視点での矩形マップの移動・取り消し・攻撃対象・背後ダメージ・待機方向・キーボード操作をChromiumとWebKitで検査します。

画面は1440×900、390×844、320×480、667×375で検査しています。今回の公開前確認ではWebKitでも主要画面と操作を確認しました。
