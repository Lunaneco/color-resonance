# Color Resonance — 夜空の黒と透明の剣

物語とターン制の戦闘を楽しむ、ブラウザ向けゲームです。HTML、CSS、JavaScriptで動作し、ビルドやサーバー側の処理は不要です。

**プレイする:** https://lunaneco.github.io/color-resonance/

**画像生成素材:** [キャラクター・動作GIF・技エフェクトの素材一覧](https://lunaneco.github.io/color-resonance/assets/generated/)。18種類のキャラクター、20種類の技エフェクト、127本のGIFと透過PNGを収録しています。使い方は [素材README](assets/generated/README.md) を参照してください。

## 遊び方

画面に触れて音を有効にし、「はじめから」を選んでください。

- 物語: クリックまたは Enter で読み進めます。Ctrl 長押しでスキップできます。
- 戦闘: 味方と移動先の床を選び、表示されるメニューで行動します。E でターン終了、Esc で選び直します。
- 敵の向き: 足元の橙の矢印が正面、青の二本線が背後です。HPの横の矢印と敵の情報欄でも4方向を確認できます。選んだ味方の現在位置からの攻撃は、正面・側面（+10%）・背後（+25%）として情報欄に表示されます。
- 進行状況はブラウザのローカルストレージへ自動保存します。ブラウザや端末を変えた場合、セーブは引き継がれません。
- BGM、効果音、文字の速さ、難易度は「設定」で調整できます。

マップの戦場には適正LVと選択中の難易度が表示されます。戦場や依頼を選ぶと「やさしい・ふつう・むずかしい・達人」を切り替えられ、敵のLV・HP・攻撃力と、しずくの報酬が変わります。クリア回数・最高ランク・ミッション達成は難易度別に保存されます。以前のクリア記録は「ふつう」へ引き継ぎます。難易度は出撃時に固定され、再挑戦でも同じです。

町の「依頼」には物語の進行に応じて12件のサブクエストが追加されます。初級から最上級まで、それぞれの適正LVと選択した難易度を確認できます。初回の道具報酬は各難易度で1回ずつ受け取れます（道具の所持上限は各9個）。スマートフォンでは地図をスクロールして移動できます。

精霊の召喚で絆+3、心剣に宿すと+2、精霊または宿した心剣の命中で+1、習得した技の使用で+2。精霊ごとに絆8・20・40でアリアが魔法・スキル・技を覚えます（4精霊×3種類）。「仲間・絆」で効果と習得条件を確認し、戦闘の「覚えた技」で使います。習得後は召喚や宿しなしでも使えます。絆のランクが上がると精霊や技の効果も上がり、敗北や中断でも絆・習得内容を引き継ぎます。

## 生成素材のゲーム表示

戦闘のアリア・4精霊・6種類の敵、ルノワールと6種類の会話キャラクターに、[生成素材](assets/generated/)を使用しています。移動・攻撃・被ダメージ・技発動をコマで再生し、各精霊の召喚・心剣への宿しをアニメーション付きのカットインで表示します。透明の一閃・回復・4属性の力・小さな夜空・漆黒の波は、戦場上に対応したエフェクトを重ねます。人物情報や仲間画面にも素材を表示します。

`js/art.js` が必要なPNGシートだけを読み込み、動作と技の一度だけの再生・終了を管理します。読み込みに失敗した戦闘キャラクターは従来の描画に戻ります。プレイヤーの操作範囲や戦闘処理は同じです。

## ローカルで起動

リポジトリのディレクトリで次を実行し、http://localhost:8791/ を開いてください。

```sh
python3 -m http.server 8791
```

戦闘用のデータを `fetch` で読み込むため、`index.html` を直接開くのではなく、HTTPサーバーを使います。

## 公開と更新

GitHub Pages の公開元は GitHub Actions です。`main` ブランチへ変更を push すると、`.github/workflows/deploy.yml` がJavaScriptの構文と戦闘のブラウザ回帰テストを確認し、成功した場合にゲーム本体と素材を自動で公開します。Actions 画面の「Deploy game to GitHub Pages」から手動実行もできます。

JavaScript・CSSを更新するときは、`index.html` の読み込みURLに付けた `v` の値も更新します。前のプログラムがブラウザに残っていても、同じ版の画面とゲーム処理を読み込めます。

## 戦闘のテスト

Node.js 24 で次を実行してください。テスト用のHTTPサーバーは自動で起動・終了します。

```sh
npm ci
npx playwright install chromium
npm test
```

移動と取り消し、攻撃とターン進行、回復、精霊、勝敗と再挑戦、戦闘中断、終章の切り替え、難易度別の報酬・実績、サブクエストの条件、絆と12種類の習得技、およびPC・スマートフォンの画面配置を確認します。敵の4方向の目印と攻撃位置の一致、敵ターン後の方向更新、タッチでの向き確認も対象です。生成素材の実描画・行動コマ・4精霊のカットイン・演出終了・会話キャラクター・素材読み込み失敗時の戦闘も確認します。テストでは独立したブラウザを使うので、プレイヤーのセーブデータは変更しません。
