# 星の樹と旅の装丁

ゲーム内のスキル強化を「星の樹」として表示するために、内蔵 image_gen で生成したオリジナル素材です。背景の樹と枝に、習得・強化済みの星をゲームのデータから重ねます。キャラクターの芝居を含まない抽象的なUI演出です。

| ファイル | 用途 |
| --- | --- |
| `star-grove.webp` | 強化画面の背景画、町の各画面の見出し。260 KB |
| `star-grove-source.png` | 背景の生成原本。1536×1024 |
| `bloom-sheet-source.png` | 花の光が開く6コマの透過生成原本。3列×2行 |
| `star-bloom.gif` | 強化成功時の透過GIF。192×192、8フレーム、1.4秒、約31 KB、一度だけ再生 |
| `star-bloom-still.png` | 花が開いた静止画のPNG |
| `bloom-contact.jpg` | GIFのコマを暗い背景に並べた目視確認用画像 |
| `prompts.json` | 使用した全プロンプト、生成方式、原本の対応 |
| `quality-report.json` | コマ数、尺、透過、容量の検証結果 |

`tools/build_forge_assets.py` は生成シートを等寸で切り出し、同じ寸法へ縮小してGIFに変換します。絵の再描画や生成原本の変更は行いません。GIFは透過の最終フレームで終了し、画面側も1.5秒で要素を外します。強化するたびに再生を開始し、常時ループはしません。「動きを軽減する」を有効にした場合はGIFを挿入せず、段階の点灯と成功メッセージを表示します。

原本のアルファは保持します。GIFには半透明を保存できないため、既存のゲーム素材と同じ透過閾値96と共通パレットを使っています。生成原本、6コマの一覧、実際の画面での表示を確認し、PC・スマートフォン・横向き画面で枝の操作領域を検査しています。
