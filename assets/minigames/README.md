# 休憩所の生成画像

ゲーム画面の4種類のミニゲームに使用する画像です。2026-10-05に **Codex内蔵の image_gen.imagegen** で生成しました。CLIや外部の画像生成サービスは使用していません。

| 遊び | カバー・控えめな盤面背景 | 操作に使う素材 |
| --- | --- | --- |
| 星潮の航路 | voyage-cover.webp | ship・treasure・wind・heal・reef |
| 結晶の連鎖 | crystal-cover.webp | tide・leaf・gold・prism・nova |
| 灯台の色つなぎ | lantern-cover.webp | lantern-on・lantern-off |
| 精霊のこだま | echo-cover.webp | tide・leaf・gold・prism |

4枚のカバーは768×512、12種類の道具は128×128の透過WebPです。表示する画像は合計約396KiB。生成原本は `source/` に保存し、ブラウザは最適化したWebPだけを読み込みます。原本の透明部分を保ち、画像の描き直しや人工的な背景除去はしていません。

色に加えて形・記号・名前で結晶を識別できます。点灯と消灯は別画像と「●／○」を併記します。船の現在位置、次の進路、岩礁の傷、交換できる隣、光を切り替える範囲、お手本／回答の番はHTMLとCSSで実際の状態を示します。画像の中に操作説明を焼き込んでいません。未加入キャラクターを表示する素材はありません。

- [全生成プロンプト](prompts.json)：ユーザー指定の不透明な髪と滑らかな質感の条件を含みます。
- [品質・切り出し情報](quality.json)：画像寸法、透明度、原本、切り出し座標と配送サイズ。
- [パッケージ処理](../../tools/build_minigame_assets.py)：Pillowによる矩形切り出し、同倍率での縮小、WebP保存のみ。生成済み原本から再現できます。

検証は実ブラウザで画像を読み込み、盤面の状態・キーボード・タッチ操作・途中セーブ・報酬を確認します。320×480、390×844、667×375でも、ハード盤面と主要ボタンを同時に表示し、動きの軽減にも対応しています。
