# 装備・道具・強化素材の画像

全54種類にそれぞれ専用の画像を生成しました。通常装備15、ユニーク装備28（うち伝説装備5）、消耗品5、強化素材6です。生成には組み込みの `image_gen.imagegen`（画像ごとに1回、透過背景）を使っています。API・CLIによる生成は使用していません。

- `prompts.json`: 54種類の生成プロンプトと名前・分類・由来。
- `<id>.webp`: ゲーム用の256×256透過画像。名前はゲームの所持品IDと同じです。
- `quality.json`: 元の大きさ・切り出し範囲・透過・配信用画像のSHA-256。
- `contact-sheet.webp` / `index.html`: 確認用の一覧画像と画集。
- リポジトリの `art-source/inventory/`: 元の生成PNGと生成記録 `generated.json`。元画像は変更していません。このディレクトリはPages配信に含めません。

`tools/build_inventory_assets.py` はPillowで透明な余白を矩形で切り出し、縦横比を保って縮小、中央に配置してWebPへ変換します。描き直しや背景の加工は行いません。再生成にはPillowの使えるPythonでこのスクリプトを実行してください。

画像は `js/inventory-art.js` で装備・所持品・お店・戦闘中の道具・強化レシピ・ステージ報酬・ミニゲーム報酬に表示します。名前・効果・数量はテキストで残し、装飾画像は読み上げから除外しています。未所持の装備や未加入の仲間の表示条件は既存のゲーム処理に従います。

復興編で追加した5種類の伝説装備は、王国外の各地のハード固定クエストで初回S評価時に獲得できます。追加素材の原本と正確な生成プロンプトは `art-source/restoration/prompts.json` にも記録しています。
