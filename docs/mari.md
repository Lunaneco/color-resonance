# クリスタリア復興本編とマリー

透明の国の名はクリスタリア。虹の国のパレット・パレスとは別の国であり、プリズム王国という別名は使わない。

本編クリアはクロム撃破後のエンディングまでを指す。復興コンテンツはその後に解放し、パレット王撃破では解放しない。マリーは復興本編の救出後に加入する。グランとヴァルドの友情はヴァルド戦クリア後に始まる。

マリーを復興本編の主要人物とする。第3話の苗床に灰黄色の羽根と羽音を残し、第4話に必須の通常戦「帰らない羽音」とボス戦「闇の繭」を組み込む。救出・本人が精霊として生きることを選ぶ会話・加入の後、マリーとともに記録院の戦闘を進める。第5話以降の本編を読むには、この加入を済ませる。会話の振り返りは加入後に用意するが、救出をサブクエストや寄り道にはしない。

## 物語のつながり

- 本編の羽根の声は「最後に届いた声」。雄鳥とグランは、嵐から戻らないマリーが亡くなったと思っていた。誰も身体を確認していない。マリーは嵐の黒い波に取り込まれ、外の年月から切り離された闇の中で帰る時を待っていた。
- 帰りたい声を繭から助ける。長く闇にさらされた翼が光へほどけ、本人が旅を続けることを選び、精霊になる。過去の記録から人物を複製する出来事とは区別する。リラ、王と王妃、ネリの息子の死は変えない。
- 第4話でマリーは、クリスタリアを訪れ、王妃から「残す声は、持ち主に返す」という窓の歌を聞いた記憶を持ち帰る。原本と仮の図の違いに気づく、重要な証人となる。
- 第5話ではアリアの喪失を代わりに決めず、本人の言葉を聞く。第6話ではネリの母から教わった結び目が、港と広場の修理をつなぐ。昔の人と現在の世代を取り違えない。
- 第7話では灰色の街の時計師と測った風・鐘の間隔を使い、グランと回廊の道を開く。第8話では王妃の窓の歌を最後まで歌い、港・森・谷の人々が選んだ灯へ応答を届ける。マリーの旅先での交流と知識が、アクロマの欠けた観測と最終対決に関わる。
- 結末では森の薬草、谷の修理、港の結び目を国々のあいだで運ぶ。ヴァルド加入済みなら、マリーの角の修理の約束を回収し、グランとヴァルドの友情も会話に登場する。

## セーブと戦闘

新規の旅は第4話内で加入し、通常どおり第5話へ進む。すでに第4話以降をクリアした旧セーブは、救出を読み直しても復興の進行・素材・装備・受取済み報酬を減らさず、元の本編の場面へ戻る。古い第4話途中の行番号や台詞識別子で救出を飛び越えた場合も、救出の冒頭へ戻す。再読み込みと持ち出し用ファイルにも帰還先を保存する。

マリーは召喚・エンチャントに対応する6人目の精霊。召喚は共鳴6・3ターン、全味方に2ターン追い風で移動+1。エンチャントは共鳴3・3ターン、移動+1、通常攻撃2回、命中した周り1マスを虹にする。追い風とエンチャントは重複せず、期限が切れると通常の移動へ戻る。召喚中に倒れれば、その戦闘の召喚・エンチャントは禁止。

習得経路は召喚とエンチャントを分け、各熟練8・20・40で3技ずつ。虹彩の結晶と共鳴の砂で強化し、+3に澄明の核を使う。加入前の仲間一覧・スキルツリーには未加入のマリーを出さない。スピネルの盾・防御・回復、ヴァルドの憤怒による攻撃上昇は維持する。

既存の生成マリーのRGBA素材を再利用し、羽の行動コマを召喚・攻撃・被弾に接続。心剣のカットインはアリアの既存動作セルと回復の光を重ねる。新規の画像生成やGIF作成は行っていない。

`tests/mari.test.cjs` と復興本編の進行テストで、必須救出・加入、未加入の非表示、全8話への接続、旧セーブの進行保持、セーブ持ち出し、追い風の期限・非重複・実移動をChromiumとWebKitで確認する。
