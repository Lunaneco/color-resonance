# 登場人物と動きの補完 — 1.26.2

現行の77戦場・本編/復興/最終章を確認し、魔物で代用されていた人間の兵と、固有の姿がなかった闇の繭を補った。

## 新規14種類

- 虹の近衛7人：マリナ、シオン、オーカー、アンバー、ヴィオラ、カーマイン、ヴェルデ。`docs/rainbow-guard.md` の外見・武器・立場を維持。カーマインは騎乗。
- 一般兵6種：槍兵、剣兵、弓兵、重装兵、騎兵、隊長。人間の兵を影・茨・鉛・膜で代用しない。
- 闇の繭：黒い羽と帯が帰る声を閉ざす姿。正体を隠す段階で、黄色いマリーを会話画像として出さない。

各素材に待機/移動/攻撃/被弾/力の発動を用意した。兵士と近衛は戦闘開始時に読み込み、近衛の会話にも本人の画像を使う。読み込み失敗時の既存フォールバックは保持。

## 刷新と既存素材の活用

- 馨：ユーザー提供の黒髪・灰色の瞳・黒いパーカー・白いTシャツを保持したデフォルメ姿。12セルで会話/挨拶と戦闘の攻撃/詠唱/被弾を分離。
- マリー：既存の黄金の渡り鳥を参照し、12セルで会話/挨拶と攻撃/被弾/祈りを分離。被弾に会話、攻撃に挨拶を流用しない。
- ノアール：既存の吸収・弾みの実描画セルを盤上の攻撃と被弾にも活用。吸収実行時には盤上の本人にも吸収モーションを表示。
- 守護者：特殊行動の解決時に詠唱、詠唱がない既存素材では攻撃動作を再生。クロムは既存の闇の波を維持。

## 原本と再出力

`art-source/cast-20261022/` に採用した画像生成原本、参照画像、全生成プロンプトを保存。`records.json` が採用記録。生成には組み込み imagegen を使用し、髪の不透明度と微細な質感を抑える指定を全プロンプトへ付加した。

生成アトラスのコマ位置は完全な等間隔ではないため、透明度で分離できる人物・武器の連結部分を丸ごと切り出す。人物ごとに全セル共通の倍率と足元を使って正式な等寸グリッドへ配置する。ポーズを引き伸ばしたり、武器をセル境界で切ったりしない。原本の色や絵は描き直さない。PNG内部の不透明部分を100%へ戻し、輪郭の透過は保つ。

再出力：PillowとNumPyのあるPythonで `tools/package_cast_assets.py` を実行。PNGセル、正式シート、動作GIF、マニフェスト、カタログ、品質記録を同時に更新する。ゲームはGIFではなくPNGのセルをゲーム内の時計で再生する。`tools/build_kaoru_assets.py` は旧ドット絵用の履歴であり、現行素材の再出力には使用しない。

## 物語ページ

主要人物、近衛、全兵種、現在の守護者と各地の魔物を掲載。会話に人物画像、戦場に相手の画像を添え、人物一覧では動作選択・再生・全体停止に対応。表示範囲のセルだけを再生し、タブ非表示や動きを減らす設定では停止する。復興編の姿は既存のネタバレ表示設定に従う。旧アクロマ/トキネルの設定は復活させない。

`file://` でも本文と動きが動くよう、本文のローカル読み込みと事前計算した画像範囲に対応。ゲームと同じPNG・動作列を攻略ページの書き出しで同期する。
