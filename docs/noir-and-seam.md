# ノアール・パレット王の宝具・最終章 — 1.18.0

物語の芯を書き足した版の記録。旧ルノワールをノアールに改め、パレット王を仲間から外して宝具を託す形にし、クリスタリアを光の国として位置づけた。ヴァルドの過去を書き直し、馨をラスボスとする最終章を加えた。

## 固定年表

- 十六年前より前：マリーが世界じゅうを旅する。赤い丘でヴァルドとルベラに会い、角の継ぎ目を直す。クリスタリアの王妃（アリアの生みの母）が、渡り鳥のために窓の灯を揃える。このころテラ・コッタはまだない（灰色の野原）。マリーが最後に飛んだのは十六年前で、百年前ではない。
- 十六年前の夜：馨が向こう側から落ちてくる。向こうの街の欠片がテラ・コッタになる。馨の通った穴から向こうの闇が溢れ、光の国クリスタリアへ落ちる。同じ夜、マリーは王妃の窓を見た帰りにその黒の嵐へ呑まれる。鯨が泣くのも、この夜から。同じ夜にアリアが生まれ、同時にノアも生まれる。クロムはその黒で国を覆いきって力を使い果たす。王と王妃は刃で斬られたのではない。国の光を使い果たして揺りかごを海へ流し、光が尽きたところで亡くなる。ノアだけが国に残る。
- その後：主のいないノアは「何のためにいるの」「透明の国なのに黒い」と扱われ、捨てられた色を吸い続けて黒くなり、待っていた相手と自分の役目を忘れる。黒を汚いと言われてきたクロムだけが、ノアの黒を否定しなかった。空になったクロムは、眷属のノアに、心剣が切り分けた澱を溜めさせる。戻った力で、夜を世界じゅうへ広げるため。旅のあいだ、その収穫はパレット王の布告に見せかける。
- ヴァルドの喪失：生命の実が持ち去られ、ルベラと子が亡くなる。黒い種が、その怒りに命令の形を与える。
- 本編：アクアミストの路地で、クロムがノアールをアリアに預ける。ノアは理由もわからないまま、アリアのほうへ寄っていく。名前を聞いた直後から、布の中のノアールは戦場に出る。入り江の戦いはそれより前なので、最初に並ぶのは第一幕の鐘楼前。終章の絶望では出ない。夜空になってアリアを救う役のまま。
- 吸収：マンハッタン距離2、対象のHPが最大の30%以下。飲むとその穢れは消え、経験としずくは通常の撃破と同じ。種類（土地の姿、通常種、守護者、終章のクロム）の初回だけ技が残る。同じ技を別種が教えても、技は増えない。覚えた技は戦闘の「預かった技」と、仲間の画面に出る。セーブは `party.noir`（`joined` / `skills` / `known`）。古いセーブにこの欄が無くても壊れない。進行済みの旅は、序章の命名を再び通るまで戦場に出ない。
- 第五幕：パレット王が、黒はクロムが生んだものではないこと、眷属はもとは光の国の生まれらしいことを話し、宝具を託す。色の国々の話はここで終わる。
- 終章：ノアは小さな夜空になってアリアを救い、結末で生まれと名前を思い出す。
- 復興編：クロムの剣はノアール本人ではない。アリアの隣にいたあいだに身につけた浄化と精霊の力が、力を失ったクロムの剣を組み直す。ノアールはその力を輪にしてアリアの左の薬指へ渡す（「リングにしてあげる」）。輪は物語だけで、道具にも装備にも入らない。
- 復興編のあと：最終章。馨と二つの世界を切り離す。

## システム

- パレット王はクロムと同じく人間の王で、精霊ではない。`Progression.companions` から外す。章の戦場の表示も「精霊ボス戦」ではなく「ボス戦」。戦闘の精霊一覧からも外し、パレット王の習得技は戦闘で使わない。仲間・スキル強化・便りにも出ない。虹彩の結晶は、マリーの技の素材として残す。
- `Progression.paletteRelic(unlocked)`：第五幕を読み終えて終章が開いた旅で、王笏を持つ。
- 王笏があると、そのターンの1体目の召喚ではアリアの手番が残る（`u.summonChain`）。メニューは「2体目の召喚」と「待機」だけになり、宿しや攻撃はできない。2体目の召喚で手番を終える。ターンが変わると戻る。
- ミッション `doubleSummon`：王笏で1ターンに2体を召喚した回数。依頼「城下町の色祭り」で使う。
- 依頼「星の庭の色合わせ」は、パレット王との絆を受注条件にしない。
- 最終章は `js/seam.js`。詳しくは [馨とテラ・コッタ](kaoru.md) の最終章の節。
