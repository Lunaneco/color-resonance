# 国の色の敵と難易度

## 国ごとの敵

敵の絵は新しく描かず、既存のスプライトを国の色へ染め直して使う（`js/art.js` の `tintedImage`。色相を回し、暗い部分に国の色を少し足す。種類ごとに一度だけ計算する）。ボスと守護者は元の絵のまま。定義は `js/regions.js`。

| 国 | 敵の名前（影／棘／殻／膜） | 特性 | 付く敵 |
| --- | --- | --- | --- |
| 潮の国（アクアミスト・鐘楼・復興の港） | 雨だれの影／珊瑚棘の影／錆びた錨の殻／泡の膜 | 押し流し：命中した味方を1マス押す | 影・膜 |
| 赤い丘 | くすぶる影／燠火の棘／焦げた鎧殻／煤の膜 | 燠火：命中した味方の周りの床をくすませる | 影・棘 |
| 緑の森 | 木陰の影／絡み蔦の影／苔むした殻／胞子の膜 | 絡め取り：半分の確率で移動を1ターン封じる | 棘・膜 |
| 黄金の谷 | 砂金の影／乾いた棘／金屑の殻／砂の膜 | 金の被膜：最初に受ける傷が半分 | 影・棘・膜 |
| 虹の尖塔 | 借り物の影／彩りの棘／飾り鎧の殻／塗りの膜 | 色吸い：命中すると共鳴を1奪う（敵の手番に2まで） | 棘・膜・殻 |
| 透明の国 | 霞の影／氷花の棘／曇り硝子の殻／白磁の膜 | 霞：攻撃が外れやすい（+12%） | 影・殻・膜 |

特性は弱めにし、鉛の殻にはもともとの装甲があるので金の被膜は付けない。敵を選ぶと、情報欄に特性の内容が出る。

## 戦場の雰囲気

各国に4種類（赤い丘も4種類）の雰囲気（背景・時間帯・天気や光の粒・床の色・段差の多さ）を用意し、同じ国の戦場へ順に割り当てる。物語のために作り込んだ戦場（入り江・鐘楼・本編の4ボス・終章・マリー救出の2戦）は、元の雰囲気を残す。復興編の8話は別々の雰囲気になる。

## 難易度の調整

目安として、`Board.statsFor` で出した同じレベルのアリアと敵を比べ、敵を倒すまでにアリアが受ける傷の割合を指標にした（`tests/regions-balance.test.cjs`）。外れ値をならし、次の条件をテストで保つ。

- 本編のボスは、グラン→アイビー→パレット王の順に上がる。最初のボスは入口として優しくする
- 復興編の8話は、少しずつ手ごわくなる。最後の話は最初よりはっきり重い
- 自由・サブ・伝説の戦場も、レベルとともに上がる。外れ値（指標2.3以上）は置かない

主な変更：グラン戦の影を1体減らし、スピネル戦の鉛を3体にして、パレット王戦は影を増やして鉛を減らした。星見の崖・透明の回廊・四つの絆の残響・伝説級は数をならし、復興依頼は話のレベルに応じて敵が増えるようにした。宿しと召喚が両立する分の強化は、国の特性による緊張感で相殺している。
