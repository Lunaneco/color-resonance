# 紅角のヴァルド

第三幕・赤い丘「怒りの向け先」。テラ・コッタの章の終わりで、暗い森（アイビー）と赤い丘（ヴァルド）のどちらから向かうかを選ぶ。地図では両方の場所に「物語」の印が出て、どちらから読んでもよい。折れ枝の道の通常戦 → 汚染された紅角のボス戦 → マリーの記憶と加入 → ノアールの夜（赤は持ち帰らず、ヴァルドの角に返す）の順に進む。ほかの章と同じく、章カード・戦場・仲間入り・夜の場面を持つ。難易度・評価に関係なく、戦闘後の物語を読み終えると仲間になる。旧版の丘のクリアだけでは加入しない。旧クリア・所持装備・素材の受取記録は残る。

ヴァルドは紅い龍の精霊（翼・鱗・二本の角。1.18.0で猛牛から龍へ設定を改めた。キャラクターデザインは描き直し予定で、いまの戦闘の絵は旧い姿のまま。本文は龍として読む）。赤い丘には十年に一度だけ実る「生命の実」がある。子を産む者が少し口にすると、危うい出産にも耐えられる。出産を控えた妻ルベラのために残されていたその実を、丘のふもとの男トルカが、熱の下がらない娘ニナのために持ち去った。ルベラは出産に耐えられず、生まれるはずだった子とともに亡くなった。ニナは生き延びた。ヴァルドの赤は、焚き火のような温かい赤から、黒に近い凝固した血の赤へ濁った。黒い種は、もとからあった怒りに命令の形を与えただけで、怒りそのものはヴァルド自身のもの。だからアリアは「怒っていいよ。それだけ大切だったんでしょう」から向き合う。浄化後も怒りは消えず、翼は根元の深紅から朱、橙、金へと翼の先に向かって灯る（燃やし尽くす怒りが、生きるための火に変わる）。大きな二本角の片方には、ルベラが「生まれてくる子の名前の代わり」に結んだ色褪せた赤い紐があり、ボスの姿でも焼けずに残っている。浄化後、トルカとニナが丘の境まで来る。トルカは謝罪で返せないと言い、ヴァルドは許さない。それでも娘を踏む角は持っていないと答える。理由がわかっても、免罪にはしない。マリーとの会話はかつての旅の回想として示す。グランが「帰り道の嵐」と最後の声を伝え、二人は果実を分かち合って潮の友になる。この回想ではマリーを現在の人物として扱わない。グランの最後の別れという認識は、復興本編第4話で闇に取り込まれたマリーを救出して更新する。先に救出済みの場合も、その現在を踏まえた台詞を使う。

## 戦闘

- ボスは穢れHPの2/3・1/3で理性を取り戻す。突進は一本の線 → 二筋 → 選んだ相手へ交差する線へ変わる。段階の切り替わりではくすみが広がる。予告床を虹に戻すと特殊攻撃の傷・侵食・押し出しを防ぐ。
- 攻撃倍率は0.65 → 0.80 → 0.90。理性が戻っても怒りを失うわけではなく、向け先を選べるようになる。
- S条件は12ターン以内、アリアHP65%以上、背後から3回命中。突進が広く床を侵食するので、最大くすみ条件と偶然のクリティカル条件は使わない。
- ハードのボスSのみ「赤い果実のブローチ」。通常戦のハードSは潮音のレイピア。ふつう以下はアイテムとクリア・ミッション素材。

## 仲間としての力

「怒りを攻撃力へ変える」。攻撃倍率は `1.15 + 0.4 × 失ったHP割合`。HP満タンなら+15%、残り半分なら+35%、上限は+55%。回復すると上昇分も戻る。自傷行動や防御ペナルティは加えない。

召喚は共鳴6・3ターン・初動に周り2マスへの咆哮。自身のHPから憤怒を計算する。エンチャントは共鳴3・3ターン・アリアのHPから計算し、通常攻撃を毎ターン2回使える。召喚精霊が倒れた場合、その戦闘の召喚・エンチャントは禁止。再挑戦で解除する。

エンチャント系と召喚系を各3技、熟練8・20・40で別々に習得。金継ぎの欠片と共鳴の砂で+3まで強化し、最後に澄明の核を使う。既存4精霊の性能は変更しない。スピネルは守る力として盾・防御・回復を担当する。ノアールが旅で吸収した四響はそのままで、ヴァルドの加入を自動吸収として扱わない。

## 語らいと保存

加入後、丘の「精霊たちの語らい」から会話を再生できる。グランとの友情、アイビーとの休息、スピネルの守り、パレット王との異なる色の対話を追加（1.18.0からパレット王は仲間にならないため、この会話は再生されない）。加入している精霊の会話だけを再生する。本編クリア後は二人が復興の荷車を導く後日談になる。

本編の行番号・台詞の識別子・場面・色・マップ状態を `cr_save.returnStory` に保存。寄り道途中の再読み込み・書き出し・読み込みに対応し、結末で元の本編記録へ戻る。入れ子の帰還記録や不正な帰還先はセーブ読み込み時に拒否する。

## 画像

組み込み `image_gen.imagegen` を使用。原本は `assets/generated/source/vard.png`、実装用透過画像は `sheets/vard.png` と `frames/vard/000.png`。プロンプトは `prompts-vard.json`、寸法・透過・原本ハッシュは `quality-vard.json`。原本のRGBAを保ち、縮小と透過余白への配置だけを行う。静止セルにゲームの移動・被弾・カットイン・咆哮のモーションを付ける。新規GIFや動画は作成していない。

`tests/fury.test.cjs` で実物のボス画像、段階、加入前の非表示、加入後の技ツリー、敗北・再挑戦、帰還と持ち出し、召喚・エンチャントの実ダメージ、戦闘不能制限、加入に応じた会話をChromiumとWebKitで検証する。
