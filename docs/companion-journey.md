# 精霊の加入と、森・赤い丘の物語

新しい旅の加入順はグラン → アイビー／ヴァルド（この2人は順不同）→ スピネル → パレット王。マリーはクロム撃破後の復興第4話で加入する。

第三幕解放後、茨の森と赤い果実の丘をどちらから進めてもよい。アイビーとヴァルドの加入会話を両方終えてから黄金の渓谷へ進む。虹の尖塔の物語・再戦・章の戦場は、グラン、アイビー、ヴァルド、スピネルが加入してから開く。ボスを単独の戦場で倒した戦績だけでは、ヴァルドの加入としない。

第三幕の会話は、先にヴァルドが加わっていれば森の入口に同行し、アイビー解放後に蔦の目印を結ぶ。先にアイビーが加わっていればグランと赤い丘へ行き、ヴァルド加入後に同じ目印の会話へつながる。グランとヴァルドは、どちらの順でもヴァルド戦後に意気投合する。丘での精霊の語らいは、アイビーとヴァルドの両方が加わってから開く。

アイビーは、かつてマリーに木陰と蔦の話を聞いてもらい、赤い丘へ戻るための葉の目印を残した。復興でマリーが帰ると、この約束を覚えていた2人が再び並んで旅を選ぶ。マリーの過去の交流、グランの羽根の記憶、ヴァルドの角の修理をつなぐが、加入時期を早めない。

ヴァルドは渓谷で石の子の避難を支え、スピネルの盾と一緒に帰る足場を作る。王戦では王自身の色を傷つけず、影だけを払って心剣の通る道を開く。クロム戦と結末にも同行を描く。ルノワールの四響は、従来どおり彼自身に残った碧・緑・金・紫の力であり、ヴァルド追加によって五響へ変更しない。

旧セーブでヴァルド未加入のまま第四幕／第五幕まで開いている場合は、進行や所持品を巻き戻さず、赤い丘への案内を表示する。丘の物語の帰還先も元の場面を維持する。すでに終章・復興へ進んだ旧セーブは、その続きから遊べる。

`tests/fury.test.cjs` は Chromium と WebKit で2通りの加入順、両ルートの戦闘と会話、第四幕への合流、王戦の制限、旧セーブの帰還先を検証する。`tests/progression.test.cjs` で共通の進行条件を確認する。
