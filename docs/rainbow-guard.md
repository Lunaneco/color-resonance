# 虹の近衛 — パレット王の眷属（1.24.0）

陣取り戦の指揮官として出す七人の設定と、絵の指示をまとめる。ゲームでの数値と台詞は `js/envoy.js` の `RAINBOW_GUARD` にある。

## 立ち位置

- パレット王に仕える七人の近衛。王と同じく人間で、精霊ではない。七人それぞれが虹の一色を預かり、その色の房（誓いの房）を身につけている。
- 近衛は、王の印のある命令には逆らえない。王がクロムの黒に侵されていたあいだに出た偽の布告（針みたいな字）を最初に受け取り、色を黒く塗られた。
- 塗られていても、本人の願いが命令の形にねじれて出てくる。マリナは「誰も沈まない港」を、オーカーは「誰も傷を見せずに済む村」を願っていた。台詞は、その願いと黒い命令の継ぎ目が見えるように書く。
- 倒すと黒が剥がれ、色が戻る。戻った色は周りの床に広がる（ゲームでは半径2が虹になる）。
- 陣取り戦の霧は布告の黒が霧になったもの。港では藍のシオンの黒が霧の源で、シオンが立っているあいだは霧が濃い。

## 共通の意匠

- 近衛の制服：白銀の胸当てと肩当て。胸にパレット王の紋章（六角のプリズムに、細い虹の帯が斜めに通るもの）。
- 誓いの房：本人の色の房飾り。槍なら穂先の下、剣なら柄頭、弓なら上の弭、盾なら縁、斧なら柄に結ぶ。外套の裏地も本人の色。
- 塗られた姿：本人の色の部分（房・外套の裏・飾り石・瞳の縁）を、上から黒い塗りがべったり覆っている。黒は墨のように少し垂れていて、表面に細い針のような字がうっすら浮く。瞳は暗い紫で光が鈍い。白銀の部分はくすんだ灰色。
- 戻った姿：黒が剥がれて、本人の色がはっきり戻る。白銀は明るい。表情がやわらぐ。
- 戦闘の絵は塗られた姿で描く。会話の立ち絵は、塗られた姿と戻った姿の二枚あるとよい。

## 一人ずつ

### 青のマリナ（近衛の槍）

- アクアミストの灯台守の娘。二十歳前後。背が高く、肩幅のある健康的な体つき。
- 青い短めの髪を後ろで一つに結ぶ。日に焼けた肌。まっすぐな眉。
- 長い槍（穂先の下に青い房）。白銀の胸当てに、波の線を刻んだ肩当て。青い裏地の短い外套。腰に小さな真鍮の灯（ランタン）。
- 性格：声が大きく、まっすぐで面倒見がいい。誰も沈ませたくない。
- 塗られた台詞の芯：「揃えれば、誰も迷わない。迷わなければ、誰も沈まない」

### 藍のシオン（近衛の弓）

- マリナの幼なじみ。港の測量士の息子。二十歳前後、細身で猫背気味。
- 藍色の長めの前髪が片目にかかる。表情が少ない。
- 背丈ほどの長弓（上の弭に藍の房）。軽い革鎧の上に、近衛の胸当て。藍の裏地の長いフード付き外套。
- 性格：無口で、見たくないものから目をそらす。霧は「見ずに済む」ための黒。
- 塗られた台詞の芯：「霧の中なら、誰も見ずに済む」

### 黄のオーカー（近衛の盾）

- 石の子の村の石工。三十代半ば。大柄で、腕が太い。
- 砂色の短髪、無精ひげ。目尻にしわ。
- 身の丈ほどの大盾（縁に黄色い飾り石）。片手に石工の金槌を兼ねた戦槌。厚い胸当てと籠手。
- 性格：口数は少ないが、子どもに甘い。割れ目から光が入ることを知っている。
- 塗られた台詞の芯：「割れたものは、元には戻らない。だから、見せるな」

### 橙のアンバー（近衛の斧）

- 石の子の村の料理番。二十代後半。がっしりした体つきの女性。
- 橙色の巻き毛を布で包む。そばかす。口が大きい。
- 両手斧（柄に橙の房）。前掛けの上に近衛の胸当て。袖をまくった腕。
- 性格：豪快で、温かいものを人に食べさせるのが好き。
- 塗られた台詞の芯：「冷えていれば、誰も腹が空いていることに気づかない」

### 紫のヴィオラ（近衛の長）

- 七人を束ねる長。王にいちばん近い。三十歳前後。すらりと背が高い。
- 長い紫がかった黒髪を高く結ぶ。切れ長の目。
- 細身の長剣（柄頭に紫の房）。近衛の中でいちばん装飾の多い白銀の鎧。足首まである紫の裏地の外套。
- 性格：冷静で責任感が強い。命令が偽物だと気づいたまま、門を閉じている。いちばん苦しんでいる。
- 塗られた台詞の芯：「わかっている。わかっていて、私は門を閉じている」

### 赤のカーマイン（近衛の騎兵）

- 城の厩番あがりの騎兵。二十歳前後、七人で最年少。
- 赤い逆立った短髪、八重歯。
- 細身の騎兵槍（赤い房）。赤い鞍の軽装の馬（戦闘の絵では騎乗の姿）。軽い胸当てと、赤い裏地の短いマント。
- 性格：せっかちで、走ることが好き。迷うのが怖い。
- 塗られた台詞の芯：「迷う暇なんか、黒に塗っちまえ」

### 緑のヴェルデ（近衛の弓・城の庭師）

- 城の庭師。二十代半ば。小柄な女性。
- 緑の髪を肩で切りそろえる。土で汚れた手袋。
- 小ぶりの弓（緑の房）。矢筒に蔓が絡む。庭師の前掛けに、近衛の胸当て。腰に剪定ばさみ。
- 性格：穏やかで、植物にしか心を開かない。伸びるものを守りたい。
- 塗られた台詞の芯：「伸びるものは、みんな王に逆らう」

## 絵の作り方

ゲームは `assets/generated/manifest.json` に `cmd_<id>`（`cmd_marina`、`cmd_sion`、`cmd_ocher`、`cmd_amber`、`cmd_viola`、`cmd_carmine`、`cmd_verde`）の素材があれば、その絵を使う。無いあいだは、兵の絵を近衛の色で塗って代わりにする。

- シート：4列×2行の透過PNG。ほかの素材と同じ並び（0 待機、1 息を吸う、2・3 歩く、4 攻撃の溜め、5 攻撃、6 被弾、7 力の発動）。
- アニメーション：`idle [0,1,0]`、`walk [2,0,3,0]`、`attack [0,4,5,0]`、`hurt [0,6,0]`、`cast [0,7,0]`。時間は `thorn` と同じでよい。
- 会話の立ち絵にも使うなら、`js/art.js` の `speakers` に `マリナ: 'cmd_marina'` のように足す。
