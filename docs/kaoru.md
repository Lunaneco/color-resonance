# 馨とテラ・コッタ — 1.15.0 / 1.19.0

馨は、灰色の街テラ・コッタの記録所で十年、人の言葉を写し続けた書記。街が落ちた十六年前のうち、最初の六年は名前を思い出せないまま野原を歩いている。第二幕でアリアと三日を過ごし、自分の言葉で最初の一行を書いた。以後は旅の外側にいる。復興編の最初の船には乗らず、復興編には同行しない。

## 世界の地理

クリスタリアは、アクアミストの海を挟んでテラ・コッタの反対側（地図の西）にある。終章の「黒い靄の奥」はクリスタリアで、物語を読み終えると地図上の名前も色も「クリスタリア」へ変わり、「王国復興を開く」から復興編へ入れる。馨は復興編には同行しない。テラ・コッタに残り、手帳を書き続けている。

## テラ・コッタに戦闘はない

第二幕の「切り分けるものが、ここにはない」に合わせ、街から戦場をすべて外した。唯一の例外は 1.18.0 の最終章「灰色の継ぎ目」の馨戦で、町の店や章の戦場には戦闘を足していない。第二幕の一文は、街の灰色が「この世界の穢れ」ではなく向こう側のものだった、という伏線として読める。

- 第二幕の最後に挟まっていた通常戦・ボス戦（時針のトキネル）を削除。第二幕は馨との三日間と夜で終わる。
- 町の依頼4件（止まった小さな時計・苦い果実と手紙・鳥たちの帰り道・花守りの試練）は削除せず、アクアミストの依頼板へ移した。報酬・難易度・ミッションは変えていない。
- 伝説級「千彩の樹海」は「緑の森の奥」（迷いの森の奥）の地図ノードへ移した。
- 復興編の守り手（水紐のリヴェラ・紙翼のフォリオ）が属する町の表示をテラ・コッタから外した。

地図のテラ・コッタには、店・色と音の休憩所・スキル強化・馨の手帳だけがある。本編を読み終えると、地図のテラ・コッタの土地は灰色から街の名と同じ茶色へ変わる。

## 手帳の書き手

ワールドマップの「手帳」は、馨が書いているという位置づけ。

- 第二幕を読み終えるまでは、書き手の名が読めない手帳として表示する。読み終えると「馨の手帳」になり、馨の絵が表紙に出る。
- 読み終えた各章に「馨の書き込み」を添える。精霊の便りは、馨が一字ずつ写したもの。
- 手帳の本文・絆の便り・旅のしるしの条件は変えていない。進行の判定は章ごとの読了で行い、並行する「第三幕・赤い丘」も一章として数える。

## 復興編での馨（1.19.0）

馨は復興編に同行しない。テラ・コッタに残り、手帳を書き続けている。修理簿はアリアとネリたちが書く。

復興編は、クロムが止めたあとも国へ滲み続ける黒の出どころを追う話になった。黒は時計のような音を立て、「正しく写せ」「次へ回せ」という誰でもない言葉を運ぶ。最終話で観測塔のレンズが黒い糸の先にテラ・コッタを映し、アリアとクロムは東へ向かう。

## 馨のカフェ（廃止）

独立した後日談「馨のカフェ」はなくした。カフェの場面（三杯目のカモミール、旅から戻ったら続きを書く約束）は、最終章の冒頭に入っている。旧版でカフェを読みかけていた記録は、開いても元の場所へ戻るだけにしてある（`SCRIPT.kaoru_cafe` は `@sideend` だけ）。

## 馨の絵

ユーザー提供の戦術RPG風ドット絵キャラクターシートを参照に、馨の素材を差し替えた（`art-source/kaoru/reference.webp`）。

- 画像生成は使わず、シートの戦闘アニメ行（待機・歩き・勝利）から切り出して再構成している。背景と地面の影を除き、全ポーズを同じ倍率・同じ足元で4×2のコマへ並べた。
- 待機・息づかい・移動2コマ（歩きの左右反転）・会話2コマ（うなずき）・挨拶2コマ（手を上げる）。既存の動作定義とGIF名は変えていない。
- 低頭身のため、会話の立ち絵は他の人物より小さめに置く（`speaker-art.chibi`）。
- `python3 tools/build_kaoru_assets.py`（Pillow・numpy・scipy）で、`assets/generated/source|sheets|frames|gifs/kaoru`、レビュー画像、素材一覧のデータ、品質記録、`prompts.json` の出自記録を更新する。

## 検証

`tests/kaoru.test.cjs` で、テラ・コッタに戦場が残らないこと、第二幕末の選択と地図の「物語」の印、章えらびと赤い丘の再読、復興編の馨の台詞、手帳の書き手、後日談の帰還先、馨の絵の寸法・透過・立ち絵の描画を確認する。

## 最終章「灰色の継ぎ目」（1.18.0）

馨は、この世界の人間ではない。向こう側（現実の世界）で、知らない人の怒りや悲しみを正しく写して次へ回す仕事をしていた。ある夜「ここにいたくない」と思い、灰色の野原へ落ちた。足元には、向こうの街の欠片（時計、記録所、カフェの窓枠）が一緒に落ちていた。それがテラ・コッタで、十六年前、アリアが生まれた夜のこと。馨が通った穴は閉じず、馨がいる限り二つの世界は馨で繋がったまま。向こうの闇はその穴から溢れ、いちばん明るい光の国クリスタリアへ流れた。クロムはそれを拾い、ノアに吸わせて国へ流した。

- 開く条件：復興編を読み終えた旅。地図のテラ・コッタに「最終章へ」が出る。
- クロムと馨の出会い：二人はこの章のカフェで初めて会う。馨は手帳に何度も書いた「黒いコートの人」としてクロムを知っていて、クロムはアリアの話の中の書記として馨の名前だけを知っていた。本編の記録を動かさない寄り道（`returnStory`）として読み、読み終えると元の記録へ戻る。何度でも読み返せる。
- 伏線：第二幕でグランが「この街の話はマリーから一度も聞いたことがない」と言う。第五幕の終わりで、光の国に黒が落ちた話の途中、馨のペンが一度止まる。エピローグのカフェで、馨の音の底から、遠くへ伸びる細い糸のようなチクタクが聞こえる。
- 戦闘：`BOARDS.seam`（12×10、アリアとクロムの二人、灯なし）。ボスは闇の降り注ぐ馨で、`GuardianCombat.register` で登録した守り手型。予告は `clock`（時計の刻みのような市松）、効果は守りをはがす `unguard`。HPの名前は「降り注いだ闇HP」で、馨自身ではなく降り注いだ闇の厚さを表す。2/3・1/3で声が変わる。ミッションは20ターン以内・二人のHP60%以上・背後から3回。ハードのS評価で「透明の鞘」。
- 結末：切り分けても闇は降り続ける。馨は、向こうにいた頃の話し方（俺）で「俺ごと、向こうとここを切り離してくれ」と頼む。心剣は何も壊さず、混ざりこんだものだけを分ける剣なので、切るのは馨ではなく、混ざった二つの世界のあいだの糸。アリアは「嫌だ」と言ってから、刃を当てる。向こうから来た灰色（時計塔・記録所・野原）は向こうへ帰り、ここで色を持ったもの（窓枠、花、青と橙の上着）だけが残る。ノアは馨の茶色をひとつ運ぶ。手帳はアリアが受け取り、自分の一行を書く。三杯目のカモミールは「向こうの友だちの分」と決める。
- 読み終えたあと：最終章を何度でも読み返せる。
- `@sealed` で `sealed` を記録する。セーブの検証は `seam` と `sealed` を受け付ける。
