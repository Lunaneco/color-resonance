# 馨とテラ・コッタ — 1.15.0

馨は、灰色の街テラ・コッタの記録所で十年、人の言葉を写し続けた書記。第二幕でアリアと三日を過ごし、自分の言葉で最初の一行を書いた。以後は旅の外側にいながら、物語の要所と復興編に関わる。

## 世界の地理

クリスタリアは、アクアミストの海を挟んでテラ・コッタの反対側（地図の西）にある。終章の「黒い靄の奥」はクリスタリアで、物語を読み終えると地図上の名前も色も「クリスタリア」へ変わり、「王国復興を開く」から復興編へ入れる。馨は復興編の第1話で、テラ・コッタからアクアミストの港を回る最初の船で来る。

## テラ・コッタに戦闘はない

第二幕の「切り分けるものが、ここにはない」に合わせ、街から戦場をすべて外した。

- 第二幕の最後に挟まっていた通常戦・ボス戦（時針のトキネル）を削除。第二幕は馨との三日間と夜で終わる。
- 町の依頼4件（止まった小さな時計・苦い果実と手紙・鳥たちの帰り道・花守りの試練）は削除せず、アクアミストの依頼板へ移した。報酬・難易度・ミッションは変えていない。
- 伝説級「千彩の樹海」は「緑の森の奥」（迷いの森の奥）の地図ノードへ移した。
- 復興編の守り手（水紐のリヴェラ・紙翼のフォリオ）が属する町の表示をテラ・コッタから外した。

地図のテラ・コッタには、店・色と音の休憩所・スキル強化・馨の手帳だけがある。本編を読み終えると、地図のテラ・コッタの土地は灰色から街の名と同じ茶色へ変わる。

## 手帳の書き手

ワールドマップの「手帳」は、馨が書いているという位置づけ。

- 第二幕を読み終えるまでは、書き手の名が読めない手帳として表示する。読み終えると「馨の手帳」になり、馨の絵が表紙に出る。
- 読み終えた各章に「馨の書き込み」を添える。精霊の便りは、馨が一字ずつ写したもの。
- 手帳の本文・絆の便り・旅のしるしの条件は変えていない。進行の判定は章ごとの読了で行い、並行する「第三幕・赤い丘」も一章として数える。

## 復興編での馨

第1話で最初の船に乗って港へ来て、修理簿の書き手になる。戦闘には出ない。写すことと聞くことで、各話の事実をたぐる。

| 話 | 馨がすること |
| --- | --- |
| 1 | 修理簿の書き手になる。ネリの「礼は言わない」を丸めずに記録する |
| 2 | 水位記録の字の癖のなさから、記録が「補われた」ものだと見抜く |
| 3 | 消えた名札を、筆圧の跡から書き直す（本人が直すまで「仮」と添える）。削られた陶板の二行目を写し取る |
| 4 | 二枚の設計図を筆跡で見分ける。マリーの窓の歌を聞いたとおりに書き、抜けていた節を並べて残す |
| 5 | リラの声を代わりに書かない。黙ってカモミールを置く（第二幕でアリアが馨にしたことの返し） |
| 6 | 感謝も拒絶も同じ大きさの字で記録し、「不一致は誤りではなく記録」と答える |
| 7 | 修理簿に署名を求める。アリアは「クリスタ」ではなく「アリア」と書く |
| 8 | 市民の返事を塔で読み上げる。揃えて写す機械だった自分と、アクロマを重ねる |
| エピローグ | 最後の頁に一行を足し、手帳を地図の上でも読めるようにしたと伝える |

## 馨のカフェ（後日談）

復興編を最後まで読み終えると、地図のテラ・コッタに「馨のカフェへ」が開く。戦闘のない後日談で、第二幕の約束（旅から戻ったら、また一緒に書く）に答える。読み終えると、読み始めた時点の記録へ戻る。何度でも読み返せる。

## 馨の絵

ユーザー提供の戦術RPG風ドット絵キャラクターシートを参照に、馨の素材を差し替えた（`art-source/kaoru/reference.webp`）。

- 画像生成は使わず、シートの戦闘アニメ行（待機・歩き・勝利）から切り出して再構成している。背景と地面の影を除き、全ポーズを同じ倍率・同じ足元で4×2のコマへ並べた。
- 待機・息づかい・移動2コマ（歩きの左右反転）・会話2コマ（うなずき）・挨拶2コマ（手を上げる）。既存の動作定義とGIF名は変えていない。
- 低頭身のため、会話の立ち絵は他の人物より小さめに置く（`speaker-art.chibi`）。
- `python3 tools/build_kaoru_assets.py`（Pillow・numpy・scipy）で、`assets/generated/source|sheets|frames|gifs/kaoru`、レビュー画像、素材一覧のデータ、品質記録、`prompts.json` の出自記録を更新する。
