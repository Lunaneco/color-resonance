# システム評（辛口）

対象は、このリポジトリの戦闘・盤面・成長・しずく・ミニゲーム・地図・難易度・手応え・やり直しである。物語の文章は評さない。市販の戦術RPG（ファイナルファンタジータクティクス、ファイアーエムブレム、トライアングルストラテジー、タクティクスオウガ）を物差しにする。甘い点は付けない。

ノアールの吸収は、この評を書いた時点で入っている。収集ギミックとしては動く。戦闘の構造は、それで良くなっていない。

## 最悪のものから

1. **しずくは通貨ではない。** 撃破は `8 + lv * 2`（`js/board.js` の `defeat`）。クリア加算は敵の平均レベル×10+30が基準で、Sは1.5倍、やさしいはさらに0.8倍（`settle` と `js/progression.js` の `difficulties.*.reward`）。序盤、Lv1の影が3体なら撃破金だけで30、クリア約40、ふつうのSで合計およそ105。最初の武器「硝子の刻印」は120（`js/world.js` の `e_glass`）。1戦で店の入口がほぼ開く。最上位の「虹彩の刻印」は1600、「星織りのドレス」は1700。中盤の核を数体落とせば届く。払えない、という場面が無い。装備は一度買えば終わりで、維持費も売却も無い。素材の店値は砂25、潮・若葉55、金継ぎ70、虹彩85、核300。上限まで買う金は、戦闘報酬の横を流れる端数である。
2. **成長に選択が無い。** `GROW` は `[基礎, レベルあたり]` の直線だけ（アリアHP `[60, 10]`、攻撃 `[18, 3.2]`）。クラスも技能点も、外す技も無い。絆はランクごとにHP+5%・攻撃+4%・守り+2%程度。覚えた技は36種あるが、覚える条件は熟練8・20・40の消化である。ビルドではなく、履修表だ。
3. **地図はフィールドではない。** `js/world.js` のワールドはノードをクリックして出撃する図である。歩く地面、隠れた道、その場の遭遇、昼夜で変わる危険、どれも無い。探索を評する欄が、メニューの並びを評する欄になっている。
4. **難易度は係数である。** やさしいは推奨LV-1、敵HP×0.85、味方が受けるダメージ×0.6（`calcDamage`）。ハードは推奨LV+3、敵LV+2、HP×1.15、攻撃×1.08、しずく×1.5。（1.29.0 から敵のLVは難易度で変えず、同じ強さを能力値だけで付ける。`Progression.difficulties` の `power`）新しい敵の動きも、禁止手も、マップの別解も無い。数字を太くしただけだ。
5. **盤は戦術の形をしているが、中身は塗り絵と総当たりである。** 正面・側面・背後（背後+25%、側面+10%）、高低差（上から+15%、下から×0.9）、床の加護（25% / 45% / 65%）はある。視点の90度回転もある。そこまでは市販作の入口に立っている。その先が無い。ゾーン・オブ・コントロールも、反撃も、武器の相性も、耐久資源の配置も無い。敵AIは到達マスから与ダメージが最大の相手を選ぶ（`enemyAct`。アリアに+6、ノアールに-8、削り切れそうなら+60）。役割が無い。マップは `genMap` の乱数で、章ごとのセットピースではない。床を虹に塗ることが、位置どりより強い。
6. **戦闘の資源が締まらない。** 共鳴の上限は12。召喚6、宿し3、祈り2、浄化2。命中するたびに共鳴が戻り、撃破でさらに戻る。枯渇させて勝ち筋を捨てる、という判断がほぼ起きない。ダメージ式は攻撃×補正−守りの半分で、最低1。外れは一律5%に、特性と床で+12%が乗る程度（`strike`）。先読みの材料が、画面に出ない。
7. **ミニゲームは本編の横に置いた宿題である。** 灯台・こだま・航海・結晶の4つ（`js/minigames.js`）。評価C/B/A/Sのしずく上限は、やさしい20/35/50/70、ふつう30/50/75/100、ハード40/70/100/140。戦闘の判断とは繋がっていない。核や宝石の袋を埋めるための、別ゲーだ。
8. **やり直しは「もう一度、同じ章」である。** 難易度3つとミッションのS、復興編、伝説戦はある。ニューゲームプラスは無い。分岐で戦闘のルールが変わることも無い。2周目に残るのは、取り忘れたSと、店の残りだけだ。
9. **手応えは説明文に頼っている。** チュートリアルとヘルプは丁寧で、誤操作の戻りもある。その代わり、コマンドは文章の壁で、撃つ前のダメージ予告が無い。床の割合は帯の数字である。当たった理由は、たまに浮く「背後から」程度。市販作が1アイコンで示すことを、段落で補っている。
10. **ノアールの吸収は、上のどれも直していない。** 距離2、HP30%以下、種類の初回だけ技。守護者はHPが2/3と1/3で止まるので、最後の段階のフィニッシャーにしかならない。それは正しい抑制である。同時に、彼女は弱い直線成長の3人目で、覚えた技の威力は自分の低い攻撃に0.4〜0.95を掛けた程度だ。コレクションとしては機能する。戦術の層にはなっていない。復興編でアリアへ渡す輪は物語だけで、装備にも店にも入っていない。経済の穴は、その輪では埋まらない。

| 難易度曲線 | **4 / 10** | 章が進むと推奨LVは上がる。難易度設定はHPとレベルの係数（やさしい0.85と被ダメ0.6、ハード1.15と1.08）。序盤の入り江はチュートリアルとして機能する。中盤以降は「同じ手順を、厚いHPに対してやる」。曲線ではなく、同じ坂に傾斜を書いただけ。 |

## 市販作のどこに負けるか

ファイナルファンタジータクティクスは、同じマス目と高低と向きを、職業とCTと範囲技で「誰を育てたか」に結びつけた。ここには職業が無い。ファイアーエムブレムは、武器の相性と、倒される怖さと、限られた救援で1マスの価値を作る。ここはアリアかクロムが倒れるまで負けがなく、ノアールは倒れても布へ戻るだけなので、怖いマスが無い。トライアングルストラテジーは、地形そのものが勝ち筋になるようマップを人が置いた。ここのマップは生成される。タクティクスオウガは、同じ戦場でも階級と忠誠と編成で別の戦いになる。ここは難易度を変えても、並ぶユニットの種類が変わらない。

勝てている場所は、床の割合が攻防のルールになっていること、守護者の段階で「まだ削り切れない」が言葉と床で見えること、終章が絶望から夜空へルールを変えること。この3つは、係数を盛っただけのゲームには無い。ここを伸ばすべきで、技の種類を36から50に増やす方向へは伸ばすべきでない。

## 優先して直すこと

1. **しずくを、足りないものにする。** 序盤Sで105前後なら、最初の武器は120のまま売らず、200〜280にずらす。最上装備は1600のまま、中盤の1戦が200を超えるなら報酬のS倍率を1.5から1.15へ落とすか、撃破金 `8+lv*2` を `4+lv` に落とす。維持費が嫌なら、ユニーク以外は「所持1つまで、買い替えで前の店値の半分が戻る」だけでも、買う順番が判断になる。今は判断が無い。
2. **章ボスのマップを、生成に任せない。** 入り江、グラン、アイビー、スピネル、王、クロムの6枚だけ、人が置いた高低と障害でよい。自由戦は生成のままでいい。AIには「核は産む、茨は遠いマスを維持する、鉛は虹の床を踏まない」の3役を足す。最大ダメージ追いは雑魚だけでいい。
3. **成長を1回だけ選ばせる。** アリアのLv4、8、12で、攻撃 / 守り / 共鳴上限+2、の3択を1つ。直線の `GROW` は残してよい。選択がゼロなのが問題で、スキルツリーを増やすことではない。
4. **ハードはルールを1つ変える。** HP×1.15は残してよい。それに加えて、ハードだけ反撃1か、共鳴の自然回復を0にする。やさしいは被ダメ0.6を残し、チュートリアルの外れを消す。係数だけの3段は、難易度選択に見えて、体力測定である。
5. **撃つ前に、予想ダメージを出す。** 対象マスに「およそN」と、背後か側面かを出す。ヘルプの段落は、その表示のあとで短くする。文章で補っているあいだは、手応えが説明責任になっている。
6. **ミニゲームの報酬を、戦闘の1ルールに繋ぐ。** しずく20〜140は経済の足しにならない（上の通り、1戦のほうが大きい）。灯台Sで次戦の開始共鳴+1、結晶Sで床の25%加護が20%から、のように、遊びが次の戦場の数字を1つ動かす。それが嫌なら、評価報酬のしずく表示をやめる。今の表示は、重要な報酬があるように見せている。
7. **吸収の30%と距離2は、緩めるな。** 守護者は2/3と1/3でHPが止まる（`GuardianCombat.damage`）。30%は最後の段階でしか届かない。これを50%にすると、段階の意味が死ぬ。技の威力をアリア並みに上げるのも同じで、彼女は消す役であり、与ダメ役ではない。直すなら、覚えた技の一覧が戦闘前に「この章でまだ吸っていない種類」を示すこと。それ以上は要らない。

総合して、このゲームのシステムは「読ませるための戦闘」としては5点前後、「戦術RPGとして金を取る骨格」としては4点を超えない。床と守護者と終章のルール変化だけが、その評価を3点まで落とさせない理由である。
