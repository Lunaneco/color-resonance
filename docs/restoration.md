# 復興編 — 今日の色で、明日の道へ

本編エピローグを読み終えた後、地図の「王国復興」から始めます。以前のクリア済みセーブでも開始可能です。最初の会話で人間のクロムが加入します。未加入の段階で仲間の姿や新戦場を表示しません。

## 戦闘と進行

本編8戦・段階解放の復興依頼12戦・王国外の伝説クエスト5戦、計25戦を追加しました。本編は港、水鏡、果樹園、記録院、家の丘、広場、回廊、観測塔を巡ります。従来の本編・自由戦闘・依頼の計23戦に対し、クリア後も同程度の戦闘数があります。

アリアとクロムを個別に操作し、毎ターンそれぞれ移動・行動できます。クロムは召喚期限のない人間の仲間で、攻撃・独立したLV/経験値・夜の祈り・共有道具・待機の向き選択を持ちます。二人とも共鳴2の「浄化」で2マス以内の床を選び、周辺を虹に戻せます。番号のついた灯を直接選ぶと点灯します。敵の全滅と全灯の点灯がクリア条件です。防壁のある核は全灯が点くと攻撃可能になります。どちらかが倒れた場合は再挑戦です。

灯は地形生成後に、人間が歩いて到達できる床から配置します。戦闘マップの回転は従来通り90度単位。アリアの床は通常の地形に45%の虹色エフェクトを重ねます。

本編は適正LV16〜30、ハードは+3。物語で次の土地を解放し、過去の土地を読み返せます。戦場を再び遊ぶ際は依頼と同じ難易度選択画面を使います。復興依頼も3段階で、実績・報酬を難易度ごとに保存します。

## ルノワールの四響エンチャント

クロムがルノワールの剣を通して使用。共鳴6、1戦闘につき1回、3ターン有効。発動で行動を消費しません。

- 通常攻撃は毎ターン2回、射程2、攻撃力+25%。
- 守りと鉛を貫通し、押し流し・1ターンの拘束・与えたダメージの30%吸収・虹床の拡張を同時に適用。
- 他の精霊から吸収し、ルノワール自身に定着した能力です。精霊が全員戦闘不能でも発動・継続できます。
- 他の精霊の召喚中も使用可能。アリアの召喚にも干渉しません。クロム自身は精霊を召喚できません。
- 3ターンで効果が終わっても、その戦闘中の使用回数は戻りません。再挑戦・次の戦闘で1回へ戻ります。
- 四響での撃破はエンチャント撃破ミッションへ計上。元の精霊の絆・熟練を同時に増やすことはありません。

アリアの通常の召喚・エンチャントでは、倒された精霊をその戦闘中に再使用できない従来のルールを維持しています。

難易度の上限はハードのまま。伝説級はハード固定の専用戦場で、全ミッションを達成した初S評価時に装備を獲得します。S未達でも通常のクリア報酬は入手できます。

| 既存の事実 | 復興編への接続 | 新しい物語での扱い |

| クロムは黒が悪だから敗れたのではない | 白い膜と奪った色を切り分け、人間として生きる | 自分の侵攻の責任を認め、修理を続ける |

真の管理者アクロマは、王国を守る校正装置です。観測を失ったまま、復興で戻った水車の電力によって再起動します。「違いを消せば誰も傷つかない」という保護の命令が暴走。これはクロムを以前から操っていた黒幕ではなく、彼の選択を免責しません。港の三つの音、水面の均一化、苗の名札、二枚の設計図を経て実態を明かします。最後は色を誤りとする命令だけを切り、装置と止める権利を人々へ返します。

第5話では橋・苗床のどちらを先に修理するか選び、第6話と修理簿へ反映します。両方を直す結末で、選択の優先順だけが残ります。過去の話を再読しても最初の選択を上書きしません。

## 生成素材と再書き出し

組み込み `image_gen.imagegen` を8回使用。人間クロム4ポーズ、アクロマ4ポーズ、復興背景、伝説装備5点を生成しました。髪の不透明度100%・透過禁止、微細な質感やエッジノイズを控える指定を全プロンプトに含めています。

- `art-source/restoration/prompts.json`: 実際のプロンプト、生成原本名、採用記録。
- `art-source/restoration/`: キャラ・背景・装備の原本PNG。装備原本は `art-source/inventory/` にも保存。
- `assets/generated/source/`, `sheets/`, `frames/`: キャラの原本と実装用シート・8コマ。動作はゲームの時計でPNGコマを再生します。
- `assets/generated/quality-restoration.json`: 寸法、アルファ、実装シートのハッシュ。
- `assets/bg/restoration.jpg`: 復興画面と物語の背景。
- `assets/inventory/u_legend_*.webp`: 256px透過装備画像。全54点の所持品画集と実画面に反映。

Pillowを使い、`tools/build_restoration_assets.py` と `tools/build_inventory_assets.py` で保存した原本から書き出します。固定グリッドの透明パディング・切り出し・縮小・エンコードのみで、原本の描き直しや背景の除去は行いません。

## 検証

`tests/restoration.test.cjs` は未加入時の表示制限、旧クリアセーブからの開始、2人の操作・成長・敗北と再挑戦、灯の勝利条件、四響の4効果・戦闘不能への独立・期限・使用回数、伝説S装備と引き継ぎを検証します。8戦を実際のスクリプトの戦闘チェックポイントから進め、新しいエピローグ・地図復帰・再読み込み後の復興100%を確認します。全25戦の灯と仲間の到達性を2つの乱数種で検査し、Chromium/WebKitでPC・小型スマホ・横向き表示も確認します。実戦操作は固定の検証場面を用いるため、25戦すべてを手操作で通し攻略したという意味ではありません。
